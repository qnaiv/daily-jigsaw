# daily-jigsaw

毎日お題が変わるジグソーパズルWebアプリ / Daily jigsaw puzzle web app

その日（JST）の日付をシードにした写真が「今日のお題」になる、ブラウザで遊べるジグソーパズルです。ピース数は難易度として複数段階から選べます。

- 公開URL（予定）: https://qnaiv.github.io/daily-jigsaw/
- 設計書: [DESIGN.md](./DESIGN.md)

## 遊び方（実装予定）

1. 開くと今日のお題（写真）が自動で決まります
2. 難易度を選ぶ: 9 / 16 / 36 / 64 / 100 ピース
3. ピースをドラッグして盤面にはめていく。正解位置でスナップして固定
4. 全部はまれば完成。タイムと手数が記録されます
